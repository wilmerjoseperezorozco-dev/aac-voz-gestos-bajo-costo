# Cómo contribuir

Gracias por tu interés en este proyecto. Antes de abrir un Issue o pensar
en un Pull Request, por favor lee esto:

## Política del repositorio

Este es un proyecto de **código abierto para uso libre, con mantenimiento
único**. Esto significa:

- ✅ Puedes **descargar, ejecutar, estudiar y adaptar** el código para tu
  propio uso, bajo los términos de la licencia MIT (ver `LICENSE`).
- ✅ Puedes **abrir un Issue** para reportar un problema o sugerir una
  mejora — se lee y se considera.
- ❌ **No se aceptan Pull Requests externos** al repositorio oficial. El
  proyecto tiene un único investigador principal responsable de todo el
  código que se publica bajo su nombre, por motivos de rigor científico,
  trazabilidad de decisiones y responsabilidad sobre datos sensibles de
  investigación con una participante real.

Si tienes una mejora que te gustaría ver, la mejor vía es abrir un Issue
describiendo el problema o la idea — no un PR con el código ya escrito.

## Reportar un problema

Usa las plantillas de Issues disponibles al abrir uno nuevo. Por favor:

- No incluyas datos personales tuyos ni de terceros en el reporte.
- Describe los pasos para reproducir el problema si es un error técnico.
- Indica tu sistema operativo y versión de Python si es relevante.

## Contacto

Para temas que no encajan en un Issue público, puedes escribir al correo
que aparece en el perfil de GitHub del mantenedor.
